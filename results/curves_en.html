Does an entangling layer help? Every curve and score, at 38 and 74 parameters

Two paired experiments, plotted from the committed artefacts. M1 is a 9-qubit circuit with no two-qubit gates; M2 is the same circuit with a fixed nearest-neighbour CZ grid after each encoding stage. CZ carries no trainable parameters, so both arms have exactly the same parameter count — the only difference between them is the entangling layer.

00

What you are looking at

The comparison

Input is a 3×3×4 patch of PCA-reduced band-difference magnitudes; output is one probability for the centre pixel. One qubit per pixel, and the readout is a parameter-free mean over all nine ⟨Z⟩, so every mixer angle reaches the output in both arms.

  • M1 — separable / additive. Verified: mixed second difference on the pre-sigmoid score is ≈ 1e-16, i.e. exactly zero cross-pixel terms.
  • M2 — interacting. Same test gives 1e-2 on neighbouring pairs, so the entangler demonstrably does something before any training.
  • 38p = one circuit block, 74p = the block repeated with its own mixer angles (untied data re-uploading).

The protocol, fixed in advance

  • 5-fold city-grouped CV over the 14 labelled cities — every city is held out exactly once; both runs share the assignment (sha c22242aede982d21).
  • Per fold, one preprocessing object shared by both arms: normalization and PCA fit on that fold's training cities only.
  • Both arms start from the same parameter vector and consume the same patch stream — per-epoch stream checksums were identical in every fold of both runs.
  • Fixed budget: 50 epochs × 320 steps × batch 32, Adam lr 0.02, plain BCE. The final checkpoint is evaluated; validation never selects anything.
  • Held-out evaluation is exhaustive stride-1 over each city. AP is the primary metric.

Why Accuracy must not be the headline

Only 2.3 % of pixels are change, so Accuracy and No-change Accuracy sit between 0.91 and 0.96 for all four configurations — and at 38p the worse model scores higher (M2 0.938 vs M1 0.915). That is a τ* placement artefact, nothing more. The threshold-free metric (AP) and the imbalance-aware ones (F1*, Change Accuracy) point to M1 in all four comparisons.

06

How to read this, and what it does not say

Claims the data supports

  • A fixed nearest-neighbour CZ coupling is not a useful inductive bias for this task at either 38 or 74 parameters — consistent in direction across folds, cities, training loss and every threshold-free metric.
  • The capacity explanation for the 38p result does not hold: at 74p the gap widens rather than closes.
  • This is a controlled negative result, not a null one. The entangler was shown to create genuine cross-pixel interaction before training, so "CZ did nothing, hence no difference" is ruled out by construction.

Claims it does not support

  • No per-city or prevalence-conditioned story. Per-city ΔAP signs agree between the two capacities in only 9 of 14 cities — paris and bercy flip one way, nantes the other. Only the aggregate direction is stable.
  • No significance claims. 5 folds is a small, dependent sample and the 14 cities are not independent (cities inside a fold share a trained model). Report direction and spread; compute no p-values over them.
  • Not a statement about entanglement in general — one fixed, data-independent CZ topology on one task. A data-dependent coupling is a separate, untested question.
  • No quantum-advantage language. The parameter-matched classical baseline has not run yet.
  • 74p raises depth and parameter count together, so its gain is "increased depth/capacity under untied data re-uploading", not evidence that re-uploading as such works.

If you are running the parameter-matched classical baseline

The headline comparison is M1 (38 params) vs a 3×3 convolution 4→1 (4·3·3+1 = 37 params) — same input, same receptive field, nearly identical budget. For that table to mean anything, these have to match exactly:

  • the same PCA-4 features, refit per fold on training cities only;
  • the same folds — get_grouped_folds(5, seed=0), assignment hash c22242aede982d21;
  • the same sampler rule: city-uniform → category 1:1:2 → coordinate;
  • plain BCE (the sampler already yields ≈78:22, so an imbalance weight would double-correct);
  • final checkpoint, no selection on validation;
  • the same evaluation pixels (the valid mask) and the same τ*-selection procedure;
  • AP as the primary metric.

Baselines to beat, already measured: M1 at 38p — macro AP 0.1419, F1* 0.1994, Change Accuracy 0.347, per-fold AP [0.2519, 0.0224, 0.1299, 0.1222, 0.0784]. At 74p, macro AP 0.1617 / F1* 0.2318 / Change Accuracy 0.356.
